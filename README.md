# Mañana template language.

Mañana is a modular, whitespace-semantic, functional template language that cross-compiles
to multiple target languages. It also has an interpreter.

# Build Targets

- C#
- C++
- Clojure
- Java (source code)
- JavaScript
- JVM (bytecode)
- PHP 5
- PHP 7
- Lua
- Python
- Rust
